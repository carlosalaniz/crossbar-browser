Running Caddy as a reverse proxy

Caddy is a web server that obtains TLS certificates automatically. This guide walks through putting it in front of a self-hosted app, explains the reverse_proxy directive, and covers the health checks that keep a homelab reliable when a backend restarts in the middle of the night.

Start with a Caddyfile that names your domain and points it at the backend port. Caddy handles certificates, redirects plain HTTP to HTTPS, and sets sensible headers. You can add load balancing across several upstreams, and passive health checks remove a failing upstream for a while.
